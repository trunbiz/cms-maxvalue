# Danh sách file tạo/sửa

Triển khai các yêu cầu trong PROMPTS.md. `.env` được cập nhật riêng ở local và không được commit; các giá trị bí mật được giữ nguyên.

## Cấu hình local ngoài Git

- `.env`: Redis cache/session/queue, tiền tố Redis riêng, MEDIA_DISK=public, các biến R2/Cloudflare để trống, APP_URL=http://127.0.0.1:8010.
- `public/storage`: liên kết tới storage/app/public.
- `public/build`: bundle CSS/JS/font được sinh bởi npm run build.
